# Harrison’s Market Board

A compact live market dashboard designed for the Amazon Echo Show 5 (960 × 480).

**Live dashboard:** https://harrison-market-board.harrisonmillerr.chatgpt.site

## Display

- Scrolling ticker for major indexes and selected stocks
- S&P 500 sector heatmap
- Dark, full-screen layout optimized for a small always-on display
- No account or stock-broker login required

## Main symbols

SPY, QQQ, PLTR, NVDA, AAPL, AMZN, GOOGL, META, and BTC/USD.

## Source

The complete dashboard is contained in `index.html`. It can be opened locally or served by any static web host. Market widgets and data are provided by TradingView.
